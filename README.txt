自動販賣機操作方式

使用者模式(普通功能)：
下方有四個金額按鈕：10元、50元、100元、500元
先點擊這四個按鈕投入金額，投入的金額會顯示在【目前金額：】
在上方商品列表選取要購買的商品，接著在下方點擊【購買】按鈕
已購買的商品會顯示在下方【已購買商品：】列表
購買完畢可點擊【找零】按鈕，可重置投入的金額

管理員模式(補貨功能)：
若商品不足，可點擊左上角【管理員模式】按鈕，會跳出管理員登入系統
輸入密碼：「1234」後點擊【登入】按鈕，會回到販賣機介面
此時會多出三個按鈕：+1、+5、+10
先在商品列表選取要補貨的商品，接著利用這三個按鈕進行補貨
可以根據需要補1個、5個、10個商品
點擊【登出】按鈕可退出管理員模式
按鈕會變回【管理員模式】，再次點擊可重新登入
